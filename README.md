## 关于 NekoBridge

桌面上同时摆着好几台电脑、每台都要接一套键鼠的情况并不少见。NekoBridge 可以让你把键盘和鼠标留在其中一台电脑上，通过局域网直接控制其他设备。只要把鼠标移出屏幕边缘，控制焦点就会无缝切换到另一台电脑，键盘输入也会随之跟过去。

使用时不需要提前区分主从机。哪台电脑连着键鼠，哪台就可以直接作为控制端，而且连接是双向的——你可以用 A 控制 B，也可以随时反过来用 B 控制 A。

## 核心功能

### 键鼠共享

把鼠标移出屏幕的上下左右边缘，指针就会穿屏到旁边的电脑上。你可以在设置里调整屏幕排列顺序，只要和桌面的实际摆放位置一致，移动起来就不会搞错方向。无论什么时候想瞬间切回自己的主电脑，按下 `Ctrl+Alt+Home` 即可。

### 文件拖放

在资源管理器里选中文件或文件夹，直接拖出屏幕边缘，扔到另一台电脑的窗口里就能完成复制（原文件会保留）。甚至在你用电脑 A 控制电脑 B 的时候，也可以直接把 B 里面的文件拖到电脑 C 上。

### 剪贴板共享

文字、图片和文件都可以直接跨设备复制粘贴。对于文件，只有在真正粘贴时才会从源电脑读取数据，不会在复制的瞬间就后台占用带宽去传输（当然，粘贴时源电脑需要保持开机状态）。

### 剪贴板历史

按 `Alt+V` 可以呼出剪贴板历史记录。支持关键词搜索和按类型筛选，常用的内容还能加入收藏夹。历史记录保存在本地数据库里，重启电脑也不会丢失。最大保存条数、快捷键，以及是否记录图片和文件，都可以在设置里随时调整。

### 连接与安全

首次连接时需要输入对方屏幕上显示的一次性配对码，所有通信均通过 TLS 加密，未配对的电脑绝对无法接入控制。另外，如果连接意外中断，程序会自动释放当前处于按下状态的按键，避免出现按键“卡死”一直连发的情况。

## 安装说明

去 [Releases](https://github.com/Marigold1122/Necobridge/releases/latest) 页面下载 `NekoBridge-1.1.0-win-x64.zip`，解压到任意文件夹后运行 `NekoBridge.exe` 即可。压缩包内已经内置了 .NET 运行时，无需额外安装环境。注意不要只把 `.exe` 单独拎出来运行，请保持整个文件夹结构完整。

请确保所有互相连接的电脑使用相同版本的 NekoBridge。升级版本时，先从右下角系统托盘退出旧版，再启动新版即可，之前的配对信息会直接保留。

首次启动如果弹出 Windows 防火墙提示，请勾选允许“专用网络”通信。

## 连接步骤

假设你有两台电脑：键鼠插在左边的电脑上，现在想用它控制右边的电脑。

1. 在**右边**的电脑上打开 NekoBridge，选择「被控端」，点击「开启配对」。屏幕上会显示连接地址和一次性密钥（有效期 5 分钟）。
2. 在**左边**的电脑上选择「控制端」，输入刚刚看到的地址和密钥，点击连接。
3. 连接成功后，打开「屏幕排列」，拖动两台电脑的卡片，让它们与你桌面上的实际摆放位置保持一致。设置好后，把鼠标往右移出屏幕边缘，就能直接控制右边的电脑了。

如果有第 3 台或更多电脑，也是完全相同的步骤，从哪台电脑发起连接都可以。

## 后台常驻与退出

关闭主窗口后，程序会最小化到系统托盘继续运行。右键点击托盘图标，可以随时暂停共享、查看剪贴板历史或彻底退出程序。暂停期间会停止一切键鼠输入同步，并自动释放当前按下的按键。

## 已知限制

- 目前仅支持 Windows x64，暂不支持 macOS。
- 如果单台电脑接了多个显示器，它们会被视为一个整体的虚拟桌面。电脑之间支持上下左右排列，但排列界面里的屏幕卡片大小不代表真实分辨率比例。
- 受限于 Windows 系统安全机制，无法在 UAC 弹窗（安全桌面）、系统锁屏/登录界面，以及以管理员权限运行的窗口中输入内容（除非 NekoBridge 本身也以管理员权限运行）。
- 不保证在全屏游戏、带有反作弊系统的软件、独占键鼠输入的程序，或嵌套远程桌面等场景下正常工作。
- 符号链接（Symlink）、回收站、手机 MTP 目录、压缩包内部预览等非标准路径下的文件，不支持直接跨屏拖拽。
- 文件拖拽基于 Windows 原生 Shell 机制实现。如果接收端软件在传输中途崩溃或报错，可能会在目标路径留下未传完的残缺文件，传输后建议在资源管理器中确认一下结果。
- 拖拽大文件时，接收端需要一点时间来做写入准备，因此第一次拖过去松手时可能会有短暂的卡顿等待。
- 目前还在收集不同分辨率和不同缩放比例（DPI）混用环境下的跨屏手感反馈。如果遇到指针跳跃或体验问题，欢迎提 Issue，能顺便附上复现步骤和两台电脑的分辨率/缩放设置就更好了。

## 源码构建

编译本项目需要安装 .NET 10 SDK。

```powershell
git clone [https://github.com/Marigold1122/Necobridge.git](https://github.com/Marigold1122/Necobridge.git)
cd Necobridge

# 编译项目
.\scripts\build.ps1

# 打包生成自带运行时的发布文件夹与 zip 压缩包
.\scripts\publish.ps1
```

项目目录结构如下：

```
src/NekoBridge.Core      核心逻辑：配对、通信协议、屏幕布局、输入状态机（不依赖任何 UI 框架）
src/NekoBridge.Windows   Windows 平台实现与 WPF 界面
tools/                   本地环回测试工具与打包发布脚本
```

`Core` 层完全没有引用任何 WPF 或 Win32 句柄，所有与操作系统强相关的底层调用都集中在 `NekoBridge.Windows` 中。这样如果以后要移植到其他平台，协议和状态管理部分的代码可以直接复用。
