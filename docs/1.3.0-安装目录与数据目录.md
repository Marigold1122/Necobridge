# NekoBridge 1.3.0 安装向导

## 使用

双击 `NekoBridge-win-Setup.exe` 后，先选择程序安装目录和数据保存目录，再点“安装”。两个目录都有“浏览”，也可以直接输入完整路径。

默认位置：

- 程序：`%LocalAppData%\Programs\NekoBridge`
- 数据：`%LocalAppData%\NekoBridge`

仅为当前 Windows 用户安装，不请求管理员权限。系统目录或没有写权限的目录无法安装。安装器为自包含的单个 EXE，不要求预装 .NET。

安装完成后可直接启动。Velopack 仍负责实际安装、桌面和开始菜单快捷方式、Windows 卸载入口及后续在线更新。在线更新不改变所选数据目录。便携版同样识别当前用户保存的数据目录。

## 已有用户

安装器会读取当前用户记录的数据目录；从旧版本升级时，没有目录记录就查找原来的默认位置。默认保留原目录。

需要换位置时，请选择一个空数据目录。安装器复制配置、证书指纹标记、剪贴板历史、图片和文件副本；用 SQLite 备份接口复制数据库并检查完整性，迁移离线副本的绝对路径。只重写历史自有副本路径，不改用户原始文件路径。

数据准备完成并且程序安装成功后，才把新目录写入当前用户注册表 `Software\NekoBridge` 的 `DataDirectory`。旧数据不自动删除。程序文件不会混进迁移数据。设备证书私钥仍在当前 Windows 用户证书存储中，不导出、不随目录跨电脑迁移。

程序与数据目录不能相同或互相包含。不覆盖非空的新数据目录，也不把安装目标覆盖到其他应用、便携版或现有数据上。目录含链接/重解析点时明确拒绝。NekoBridge 还在运行时会提示先从托盘退出，不强杀进程。

若安装失败，原数据保留；已准备好的新数据目录也可能保留用于检查。不要在失败后清空原目录。再次安装可保留原数据位置，或选择另一个空的新目录。

## 卸载

Windows 的卸载操作只管理程序安装目录。新安装器强制将程序与数据分开，数据目录和定位记录默认保留。原默认目录若还含旧安装文件，不要直接删除整个目录，因为里面也可能存着历史数据。

## 构建

继续运行 `scripts/publish-updates.ps1`：

1. 发布主程序，生成 Velopack 包、在线更新索引和原生安装载荷。
2. 将原生安装载荷内嵌到 `NekoBridge.Setup`，发布单文件向导。
3. 对外输出向导版 `NekoBridge-win-Setup.exe`，原生载荷只保留在工程 `.tools`，不会作为第二个安装器放到下载列表。

## 检查范围

主程序、安装向导编译通过。InstallSmoke 仅用临时目录验证迁移、SQLite WAL 备份、自有副本路径重写、旧数据保留、目录冲突和首次安装；不访问真实用户配置、注册表、证书或已安装应用。

发布包进行了完整性和内嵌载荷检查。没有在开发机实际执行安装、卸载、用户数据迁移或在线升级，也没有截图/视觉测试。本版未配置 Authenticode 签名，Windows 可能显示未知发布者。
