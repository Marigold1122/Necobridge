# 1.02 测试包

本版按已确认的HTML调整屏幕排列外观：

- 设备屏幕框统一为相同大小，直接贴边，不再按分辨率缩放，也不显示虚线占位。
- 真实分辨率在框内中央用大字号显示，名称在左上角，本机名称绿色。
- 相邻在线设备的接缝两侧各有一条细青柠线及柔和光晕，原深色接缝保留。
- 中间的短粗双向箭头和悬停设备名称提示保留。

本轮不修改InputRouter、布局同步协议或核心穿屏映射。二维拖动、空位/离线设备保留、位置交换以及1.01的连接管理修改都包含在包内。所有参与电脑请使用同一版本；不要混用1.00及更早版本。
