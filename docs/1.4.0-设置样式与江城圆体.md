# 1.4.0 设置样式与江城圆体

按用户从78款候选中选定的“江城圆体 / JiangChengYuanTi / #59”应用到原生WPF UI。#59预览CSS元数据为3.6版500W，随包保留同版本500W和600W原文件，不调用在线字体服务、不要求用户安装。

WPF Fonts.GetFontFamilies识别实际Medium与SemiBold字重。全局及显式中文UI文字使用该家族，地址/密钥输入和Mono信息保留清晰字体。浏览器与WPF渲染不同，未宣称逐像素一致。

设置页面按已确认HTML的布局关系分为两列：文件与剪贴板、历史记录内容；外观与系统、关于及更新。布尔项使用开关样式；复用原CheckBox控件的绑定、名称和事件，保留主设置与历史齿轮共享状态、主题持久保存、开机启动、快捷键验证和更新流程。

本包包含此前尚未提交的1.3.1～1.3.5性能优化。没有新增网络协议、自动更新安装行为或字体缓存服务。两份完整CJK字体会增大包体，包体增幅不能视作同等的静息内存增幅。

字体TTF分发包为@fontpkg/jiang-cheng-yuan-ti 3.6.0，下载后校验npm SHA512；字体name表含SIL OFL1.1声明，完整许可随包Assets/Fonts/OFL-JiangChengYuanTi.txt，第三方说明已补充。字体文件未经修改。
