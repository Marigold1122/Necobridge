# 1.2.0 在线更新接入

本版开始使用 Velopack 1.2.161 管理便携包更新。

## 使用

首次需要手动下载 Velopack 生成的 NekoBridge-win-Portable.zip，完整解压后运行其中的 NekoBridge.exe；不要用原来的普通 publish 目录代替。配对及历史数据仍在用户目录，不迁移或清空。

所有更新操作在设置的“软件更新”中。启动时只检查一次，不显示弹窗、托盘通知、不自动下载或安装；关闭了Velopack默认启动自动应用更新行为。网络失败只在设置显示状态。用户点击下载后才开始下载，下载完成仍等待点击“重启并更新”。文件传输/原生拖放处于已知进行状态时拒绝重启；重启前使用现有退出流程释放输入并关闭网络。隐藏窗口状态可通过后台参数恢复。

当前GitHub只发布到1.1.0，尚未发布Velopack索引，因此现在联网检查可能显示无法检查；不是假装已是最新版。检查失败不会影响共享。首次真实升级需在发布下一版后进行端到端验收。

## 发布

运行 scripts/publish-updates.ps1。它生成便携ZIP、Setup.exe、full.nupkg和releases.win.json等文件；将这些产物一起放进同一个GitHub Release，至少包括便携ZIP、full.nupkg和releases.win.json。普通scripts/publish.ps1生成的ZIP不具备完整更新元数据。

包ID固定NekoBridge，频道win，禁止发布后更换包ID或渠道。包与SDK/vpk均固定1.2.161。GitHub源不携带私人Token，不使用不明公共下载代理。当前未配置Authenticode签名：组件的包完整性验证不等于独立发布者签名，本版不宣称具备抗源站篡改的签名验证。
