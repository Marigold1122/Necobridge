# v0.2.6 截图透明修正

修正截图剪贴板读取：按PNG、DIBV5、DIB、Bitmap原生格式提取；32位BI_RGB的保留高字节不再误当成透明通道，截图彩色像素保持可见。24位行填充、正向与倒置行序均处理。PNG及明确alpha掩码的DIBV5保留真实透明度，不使用“alpha全零就强行不透明”的泛化猜测。

验证使用合成原生COM数据对象，不访问用户系统剪贴板。逐像素验证24/32位截图、PNG透明/半透明、DIBV5透明/半透明、接收输出PNG及DIBV5，并拒绝畸形和截断位图。此前文字去循环、文件夹Shell粘贴与图片中继检查保留通过。

两端退出旧版并更新；旧版如果已经把截图编码成透明PNG，新版接收端不能凭空恢复被丢失的像素。升级后请重新截图再粘贴。驱动快捷键、文件夹复制和界面不作变更。

此为针对可复现格式问题的修复，不宣称已验证所有截图工具与聊天软件；若特定工具仍失败，请提供截图工具名和粘贴目标应用名，不需要发送私人截图内容。
