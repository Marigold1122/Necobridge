# v0.2.3 修正说明

## 鼠标移动

不再把 RawInput 传感器计数直接当作屏幕像素。适配 Microsoft PowerToys Mouse Without Borders 固定版本 f5f29e08b39cc7139ccbe4a2ec4eb4841779bc45 的默认路径：低级钩子位置减实际停靠位置取得 Windows 处理后的位移；横纵分别按源、目标屏幕宽高映射；保留小数累计。

顶部中点停靠保留，并按上游默认向屏幕内留4像素。没有改成屏幕中央，不会每个事件重新拉回中央；没有修改鼠标硬件DPI。

## 剪贴板

改为在线已配对设备之间双向纯文本同步，独立于鼠标当前控制位置。接收后保持消息ID中继，配合Windows剪贴板序列消除回环；剪贴板占用时参考上游的有限重试，不阻塞UI线程。禁用共享会取消待处理同步。不记录文本正文，不在刚配对时发送历史剪贴板。

## 文件拖放

保持目标准备、源释放、目标启动的会话确认。原生源捕获、目标DoDragDrop消息处理是本轮重点，不把核心字节传输通过视为完整跨屏验收。

失败诊断保留操作阶段、异常类型及HRESULT至LocalAppData/NekoBridge/drag-diagnostics.log；不写文件路径、正文、剪贴板内容或密钥。该文件最多约256KiB后轮换一份previous。

## 验收边界

本机已通过真实原生文件源捕获（中心与顶边）、原生 DoDragDrop 启动及取消、注册在测试窗口的 Shell 文件夹接收器完整放置；TLS 读取的小文件、嵌套目录、空目录和零字节文件落盘内容一致，源文件保留。不是仅调用核心下载接口。

本机小范围检查不等于用户双机、不同DPI/权限/网络组合验收。两端均应更新到本版本，在同一鼠标硬件档位下比较；先验证正常穿屏，再小文件和文件夹拖放。若失败，提供具体提示和拖放诊断即可，不要提供密钥或文件内容。
