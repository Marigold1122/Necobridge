# v0.2.4 定向修正

## 复现范围

物理键鼠插在左侧主控；右侧是被控。用户报告右到左文件可复制，左到右出现目标任务取消；右侧按Ctrl+C后持续提示音，复制文件后可能停止。

## 剪贴板

- 相同文本的本地重写不再产生新广播。
- 收到相同文本时先比较当前内容，不重复EmptyClipboard/SetClipboardData。
- 成功读写后才更新内容基线，失败不会污染后续复制判断。
- 保留真实A→B→A文本变化、消息ID去重、只对已配对在线设备发送、有限重试及禁用取消。
- 加入“没有内容变化的Ctrl+C”和三节点同内容重写模拟，未触碰真实剪贴板。

## 拖放

- 原生目标启动前撤走自有辅助窗口，避免首次OLE命中仍落在辅助窗口自身。
- 被控端先注入鼠标释放，再更新原生拖放的逻辑按钮状态。
- 即使系统异步状态已是抬起，仍正确结束本会话拥有的合成按下，并唤醒OLE循环。
- 取消与清理按会话匹配，旧回调不应取消新会话；失控原生STA不可悄悄复用。
- 记录准备、确认、提交阶段和异常HRESULT，不记录剪贴板正文、文件路径或配对密钥。

## 提示音

普通取消不再弹系统警告。错误最多30秒一次系统通知，仍在状态区及日志保留，防止通知风暴。此措施不替代剪贴板和拖放根因修复。

## 验收

只做与修改相关的小范围检查。真实用户两台电脑的Ctrl+C提示音和左主控到右被控仍需现场确认；不以编译通过代替用户双机验收。
