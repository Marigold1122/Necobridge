# v0.3.19 本地鼠标接管与最大化布局修正

## 输入修改

- 本地使用鼠标时不再将 Raw Input 的释放事件额外注入一次，避免与原本物理释放重复。向远端转发时仍保留释放恢复与去重。
- 被控设备上的真实移动、按下、键盘或滚轮先接管控制，再登记本地按键；通知旧控制端让出控制，撤销停车状态并释放远端持有的其他按键。
- 若物理按下与远端持有的是同一个键/按钮，不再注入会打断当前真实按下的释放。软件重放事件仍不夺取控制权。

上述是针对托盘折叠图标区域打不开、第一次本地点击被打断的代码修正。尚未在用户两台电脑上验证，不保证所有托盘问题都由此引起。

## 布局修改

- 连接页最大化不再限制在960宽的主容器；设置和屏幕排列仍使用原960限制。
- 修正内容最小高度加底部margin超过视口而必然出现滚动条的问题。只有内容确实超出时才滚动。
- 已配对设备页面上移，设备列表用带名称、地址和状态的圆角卡片，替代默认细灰列表项。
- 保留已确认的字体、深色按钮、角色选择与步骤引导，不改变屏幕排列XAML及位移映射。
