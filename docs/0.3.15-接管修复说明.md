## 建议测试

所有参与电脑使用同一个测试包，先退出旧进程后再启动：

1. 从任意一端调整屏幕左右顺序，检查另一端排列和实际穿屏方向；反向再改一次。
2. 断开、重连，检查顺序是否一致；如有第三台，检查转发后的顺序。
3. 在主设置修改条数、图片/文件记录和历史快捷键，再打开历史齿轮确认；反向修改并确认主设置同步。
4. 检查快捷键冲突提示、0 条数上限，以及原有键鼠和原生拖放是否回归。

历史默认快捷键是 Alt+V，不是普通粘贴 Ctrl+V。条数上限 0 仅表示不限条数，既有日期/磁盘容量限制不变。
