# v0.3.16-cursor 光标修复测试包

## 本轮修改

- 控制端从远端返回本机后，远端保持停车隔离，而不是在 leave 消息中直接恢复光标。
- 在线、未暂停设备继续发送低频输入心跳，保持离开设备的停车租约；失联或暂停后超时恢复，避免永久隐藏。
- 停车窗口异步显示后，在光标仍位于停车区时补发零位移鼠标事件，刷新窗口命中与光标状态，减少浏览器标签栏残留悬停。不会把已经切回或进入远端的光标再次拉回停车点。
- 进入设备、物理键鼠接管、紧急返回、暂停、断线和退出保留恢复路径。未更改键鼠位移映射或屏幕排列外观。

## 请重点验收

两端均退出旧版并运行本包。在远端浏览器打开多个标签：

1. 从控制端穿到远端，再返回控制端，等待至少 5 秒；远端指针应保持隐藏，不应持续显示标签悬停提示。
2. 再次穿入远端，确认指针恢复、可点击；连续快速来回，确认没有跳回顶部。
3. 远端物理鼠标接管、暂停共享、断网后确认指针能够恢复。
4. 回归检查拖文件与按住鼠标穿屏，源文件默认复制语义不变。

本包是光标修复待验收版，不是两项需求全部完成版。未提交、推送或覆盖旧发行包。
