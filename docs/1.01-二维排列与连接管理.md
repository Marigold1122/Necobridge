# NekoBridge 1.01 测试说明

请先从托盘退出旧程序，再让所有参与电脑运行本包。不要混用1.00或更早版本。程序仍为Windows x64自包含版，解压整个文件夹后运行NekoBridge.exe。

## 连接

“连接新设备”进入角色选择。有配对记录时，左上角显示“返回设备列表”；没有记录时不显示。退出会清掉本次密钥、关闭本次开启的配对，但不会移除原设备或断开原连接。连接请求进行中也可以返回，尚未完成的请求会被取消。

设备页只保留“连接新设备”主按钮，旁边是“调整屏幕排列”文字入口。重连和移除在每台设备状态旁。在线、离线都可以重连，重连期间图标旋转，不接受重复请求，错误显示在对应设备卡片中。移除要确认。

## 排列

保留网格画布和按分辨率缩放的屏幕框。直接往上下左右拖动，松手吸附到格子；落到已有位置会交换。不需要选择横排、竖排或两列模式。

虚线表示整台设备的占位，里面未被实线屏幕填满的部分也不能再放其他设备。本机名称为绿色。相邻在线设备的公共边界带强调色，原本的实线、虚线分别保留。边界中央的小双向箭头悬停后显示两端设备名。

鼠标、键盘和原生文件拖放共用四向目标判断。上下穿屏按横向比例确定落点，左右穿屏按纵向比例确定落点。离线设备保留原位置，不能跨过空格跳到更远设备。间接设备标识不会自动授予配对或控制权限，控制仍要求已配对并直连在线。

首次运行会把旧左右顺序迁移为同一行。二维位置写入本地配置并同步，保留版本冲突处理和保存失败回滚。

## 建议先测这些

1. 有配对记录时进入“连接新设备”，在角色选择页、控制端和被控端步骤页分别返回设备列表。
2. 对在线、离线设备分别点重连，确认只操作那台设备，错误不影响其他卡片。
3. 用四台摆田字形，再换成三台横着、一台在下面。检查四个方向，与另一端看到的排列是否一致。
4. 让其中一台离线，确认其位置不被挤走；重连和重启后检查位置。
5. 上下穿屏、按住键鼠切换、拖文件夹到另一台资源管理器；再检查原来的左右穿屏、本地鼠标接管和托盘操作。
