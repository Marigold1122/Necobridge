# v0.2.5 剪贴板与驱动快捷键

## 已实现范围

- 放行第三方驱动/软件生成的键盘、媒体键与鼠标事件，只排除NekoBridge自己标记的注入，防止自转发循环。
- 图片内容在接收端提供Bitmap、PNG、DIB及DIBV5；不是文件附件替代图像粘贴。
- 资源管理器或桌面Ctrl+C文件/文件夹后，接收端以原生虚拟文件剪贴板提供内容，由Shell在Ctrl+V目标目录读取并复制。复用既有清单、虚拟文件数据对象、加密流及中继。
- 文字同步保留内容相等比较、消息ID去回环、最新内容优先、有限锁重试。
- 替换剪贴板时退休旧offer拒绝新的读取，但不中断已经取得授权的活跃读取。明确撤销仍取消活跃读取。

## 数据与隐私

配对在线设备之间同步，不将来源绝对路径发给对端。图片按需编码为PNG并经独立文件通道传输，图片临时文件仅在程序自建GUID目录，受容量、数量及有效期限制；日志不保存剪贴板内容。

## 限制

文字262144字符；PNG64MiB、总像素16777216、单边16384以内；单帧图片。文件最多10000个清单项目、虚拟文件相对路径少于260字符，含嵌套和空目录。默认复制，不跨机移动或删除来源。请求最长1小时，继续复制后旧请求可能提前失效，源电脑应在线。

驱动直接修改本机音量/灯光、运行程序等非输入事件不在普通键鼠转发范围。软件不绕过UAC，不等于可在任意权限窗口使用。

## 验证方式

验证仅做相关编译及smoke：输入过滤纯逻辑、假剪贴板三节点同步、实际TLS流和Windows Shell临时目录接收、位图和DIB原生格式提取。未读写用户实际剪贴板，不冒充已在用户的两台电脑完成应用兼容验收。
