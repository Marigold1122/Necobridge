# 1.3.5 输入与消息分配优化

包含1.3.1～1.3.4尚未提交的优化，本轮继续减少高频路径分配，不改变界面、按键状态、穿屏目标、合并间隔或超时规则。

## 单条输入注入

每次SendInput只注入一个INPUT，之前仍创建单元素数组。现在使用ref INPUT传递栈上结构，并缓存结构尺寸；没有使用跨线程共享输入数组，没有增加unsafe代码。Windows调用参数、Marker、返回值及异常处理不变。

InputSmoke检查本机架构INPUT尺寸（x64为40字节）及引用参数声明通过。未向实际桌面注入测试事件，真实键鼠兼容性仍需验收。

## 默认字段省略

JSON序列化省略零值/null字段。读取仍使用同样的字段名、默认值、大小写和深度限制；四字节帧长度格式不变。Mode的非零字符串初始值不省略。

测试对照旧读取配置：零坐标、按钮DOWN、键盘UP、keepalive、配对握手字段、空文件/目录、空文本均恢复为相同字段值。旧完整JSON也可由新配置读取。没有改成新二进制协议。

局部Release测量：

|---|---:|---:|

PerformanceSmoke与InputSmoke定向检查通过，发布编译通过。没有启动窗口、访问实际用户剪贴板或重启当前实例。未测整进程静息内存下降，不能承诺低于当前55MB。
