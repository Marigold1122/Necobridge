# v0.3.18 已确认连接交互稿移植版

## 本轮交付

按用户在桌面 HTML 中确认的最终方向，将连接页移植为原生 WPF。不引入浏览器运行时，不改屏幕排列或主设置外观。

- 未配对首屏：主区居中的大标题“这台主机是作为…”，两个大角色卡片，角色说明与图标。
- 选择角色：首屏淡出，步骤页淡入上移。系统关闭动画时直接切换。
- 顶部持续显示横向三个圆圈和虚线，标记当前/完成步骤；下方只显示当前步骤内容，不再整列堆积。
- 控制端：准备对方 → 查找或手填地址和安全密钥 → 真实连接成功。连接错误保留在当前步骤，可修正后重试。
- 被控端：开启配对 → 本机地址、密钥、复制按钮和倒计时 → 收到新连接后完成。已有在线设备不会让添加设备流程提前跳到成功。
- 操作按钮采用15px半粗微软雅黑、深色实底、12px圆角，无绿色阴影，无白色细边框按钮。
- 连接页使用独立局部样式，不替换其他页面全局控件样式；保留深色主题所需动态资源。
- 已配对设备默认显示设备页，保留重连、连接新设备、排列与移除。角色不持久化为控制权限。
- 删除之前反馈不需要的教学/演示注释。仅真实状态、必要操作说明与错误提示保留。
- 包含前轮的共享剪贴板设置、排列同步与光标停车修复；本轮未修改输入实现。
