# NekoBridge Windows 试用版使用说明

这是供本地双机验收的 Windows 版本，不是已通过多机兼容性认证的正式发布版。macOS 尚未实现。

## 启动

1. 将整个 NekoBridge-1.2.3-win-x64 文件夹复制到每台 Windows 电脑，不要只复制 exe。
2. 双击 NekoBridge.exe。自包含发布包不要求目标电脑另装 .NET。
3. 所有电脑使用可信的同一局域网。Windows 防火墙询问时仅允许专用网络；不要关闭防火墙。
4. 窗口关闭后程序留在托盘；退出需右键托盘图标，选择“退出 NekoBridge”。

**本版所有参与设备都要换用 1.2.3。** 二维排列使用新消息格式，不要混用旧版。首次运行会把旧横排顺序迁移为同一行，保留配对信息。升级前通过托盘退出正在运行的旧版；配对和配置仍保存在原位置。

如果网络被阻止，发布目录中的“允许局域网连接.ps1”可在管理员 PowerShell 中手动执行，只允许该程序在专用网络、本地子网通信。此脚本不会自动执行。默认使用 TCP/UDP 24870；自定义端口时给脚本传入 -Port。

## 配对与键鼠共享

1. 在 B 选择“被控端”，点击“开启配对”。它会暂时显示随机密钥，只告诉自己信任的电脑。
2. 在键鼠所在的 A 选择“控制端”，按引导输入 B 的地址和配对密钥，点击“连接”。也可以先“查找附近设备”，再输入密钥。
3. 在“屏幕排列”中直接向上下左右拖动卡片。屏幕框使用相同大小，中央显示真实分辨率；拖到已有位置时交换。排列会同步到已连接设备。
4. 鼠标从电脑虚拟桌面的上下左右最外边缘穿过去，键盘随当前控制目标切换。只能进入相邻格子的已配对、直连在线设备，空位和离线格子不会被跳过。每台电脑的多个本地显示器仍作为一个整体虚拟桌面。
5. 添加 C、D、E 时重复配对。A 可作为控制中心；受控电脑之间的文件读取通过 A 中继，不需要自动互相信任。
6. 已配对设备启动后会尝试恢复连接。每张设备卡片状态旁有重连、移除图标，在线也能重连，重连不需要密钥；移除需要确认。有配对记录时，添加引导左上角可返回设备列表，不影响原连接。

**鼠标手感：** 按 Mouse Without Borders 默认绝对归一化模式适配：读取 Windows 已处理的指针位移，横向按源/目标屏宽映射、纵向按源/目标屏高映射，累计保留小数。取消 v0.2.2 的原始硬件计数与统一高度倍率。切出时仍停在离开电脑的屏幕顶部中点，参考上游向内留 4 像素；切入时从对应边缘进入。不修改硬件 DPI，也不宣称任意物理尺寸屏幕的手感绝对一致。

**紧急返回：** Ctrl+Alt+Pause 或 Ctrl+Alt+Home。 本地实际键鼠操作也会夺回受控电脑的控制权。断线或心跳超时会释放注入的按键。

配对建立后会固定设备证书；对方身份变化应先核实，再移除旧设备重新配对，不会静默接受新身份。

## 驱动快捷键

厂商驱动模拟生成的键盘按键、音量媒体键及鼠标滚轮事件会跟随当前控制目标；排除 NekoBridge 自己注入的事件，避免回环。被控端的第三方软件重放不会被误当作实体接管；要从被控端取回控制，请实际移动本地鼠标或使用实体键盘。若厂商驱动直接调用本机音量接口、运行程序或控制键盘硬件灯光，而没有生成可捕获的输入事件，这类动作不会自动搬到另一台电脑。

## 原生文件跨屏拖放

在普通桌面或资源管理器中按住文件、多选文件或文件夹，拖到有相邻设备的上下左右最外屏幕边缘，等待交接后继续拖入目标桌面或资源管理器，松手复制。

- 不是移动操作，不会删除源文件。
- 目标电脑使用 Windows 原生 OLE 拖放，保存位置和原生重名处理由目标程序决定。
- 源端临时拖放捕获不改写剪贴板。目标端先确认文件清单已准备好，才结束源端拖放；捕获失败或准备超时不会静默切屏。准备就绪不等于已经落盘。
- 文件清单需要先准备；单个文件按需通过加密连接下载到磁盘缓存，再供 Shell 读取。大文件或大量文件首次准备会有等待，并非零等待。
- A 控制 B 时，可以从 B 拖文件到 C，文件内容经 A 中继。
- 拖回文件来源电脑会取消本次跨机拖放，请重新拖动。
- 只支持可访问的普通文件系统对象；不支持符号链接/重解析点、回收站、手机设备、ZIP 内部对象等虚拟 Shell 项目。超长虚拟文件相对路径会明确拒绝，不会截断。
- 原生 Shell 拖放不保证整批事务回滚；目标程序失败时可能已经生成部分文件，请检查实际目标目录。
- “已发送”代表接收流已完整消费，不等同于 Shell 已完成最后的目标落盘。以目标文件和资源管理器提示为准。

**这部分需要你在两台真实电脑上验收。** 单机回环检查不能代替真实 Explorer 拖放、不同 DPI、Wi-Fi 延迟和大文件体验验证。

## 跨机复制粘贴

开启两端“同步剪贴板（文字、图片、文件）”后，在任一电脑复制，再在另一台粘贴：

- 文字：普通Ctrl+C/Ctrl+V，最多262144字符。
- 图片内容：截图、浏览器复制图片或画图里的图像，会以PNG、Bitmap、DIB/DIBV5兼容格式提供；在另一台画图或支持图片的聊天框粘贴。不是把图片内容冒充成图片文件。
- 文件及文件夹：在桌面或资源管理器Ctrl+C，切到另一台的桌面或资源管理器目标目录Ctrl+V。支持多选、嵌套和空目录；默认只复制，即使来源是剪切也不跨机删除源文件。
- 文件粘贴按需通过局域网读取，源电脑需在线。单份文件清单最多10000项，Shell相对路径需少于260字符。复制请求最多保留1小时；继续复制会让较老请求失效，因此不要把系统剪贴板当作长期文件备份。
- 图片PNG最多64MiB，单边不超过16384像素，总像素不超过16777216；超限会提示而不是静默截断。部分应用的私有剪贴板格式、动画、富文本排版不在本版范围。
- 新复制会覆盖先前剪贴板；退出软件后依赖源端读取的虚拟文件剪贴板不可继续使用。图片临时缓存仅使用软件自己建立的随机目录，有容量和数量限制，退出时清理，不删除用户来源。

所有参与设备请使用同一版本1.2.3。共享仍只在已配对在线设备之间，不在刚配对时主动发送复制历史。

## 剪贴板历史（Alt+V）

- 默认Alt+V呼出，托盘也有“剪贴板历史”。主设置页和历史面板齿轮共用设置；点击快捷键区域录入新组合，冲突会明确提示并保留原快捷键。不会接管Win+V或关闭Windows系统历史。
- 复制发生后才记录，不扫描已有系统剪贴板、不导入Windows或EcoPaste历史。已记录的文字、图片使用本地SQLite和图片文件持久保存，重启软件或关机后仍可查看和复制。数据库位于LocalAppData/NekoBridge/ClipboardHistory。
- 支持文字/图片/文件筛选、搜索、收藏、删除、清空。每条右上角有“复制”按钮，双击或Enter也只复制，之后自行Ctrl+V。已移除自动粘贴，不会从历史面板主动向其他窗口发送粘贴快捷键。
- “本机历史保留条数”直接输入上限：0为不限条数，可填1000、9999等非负整数。默认1000条；原有30天和512MiB容量规则仍生效，0不是无限磁盘。列表按页读取，接近底部自动续载，分类与搜索在数据库中进行。收藏不按日期过期，但仍计入数量/容量；收藏占满上限时明确提示，不暗自删除。
- 文件默认保存来源引用，不自动复制大文件。点击“保存副本”才下载或复制到历史专属目录，随后来源电脑关机也可用；没有副本时，来源离线/路径消失/分享过期会明确报错。删除历史或清空会删除其离线副本，但不删除用户原始文件。
- 在线共享的实际复制内容会在各端分别保存，来源名可查看。未在线时遗漏的旧记录不自动回填，刚配对不会上传整库；删除和收藏仅作用于本机历史，不自动删除另一台的记录。
- 历史内容保存在当前用户目录，未做数据库应用层加密；系统磁盘加密可另行启用。密码、私钥等敏感内容也可能进入历史，请勿复制不希望保存的内容，或及时删除/清空。网络剪贴板共享开关与本地历史独立，关闭共享仍会记录本地复制。

## 界面范围

界面主入口仍为「连接、屏幕排列、设置」。剪贴板历史通过Alt+V或托盘打开；文件传输内置在原生跨屏拖放里，不新增文件发送页面或传输记录中心。失败信息通过即时提示和本地诊断日志报告。

## 设置与隐私

- 设备配置、信任列表和诊断记录位于当前用户 LocalAppData/NekoBridge。拖放失败阶段、异常类型和 HRESULT 写入 drag-diagnostics.log，不记录文件正文、剪贴板正文、配对密钥或文件路径。
- 设备证书私钥保存在当前 Windows 用户的证书/密钥存储中，不随程序包分发。
- 配对密钥仅临时驻留内存，不写入配置和诊断。
- 正常拖放取消只在状态区提示，不反复弹系统警告；错误通知最多30秒一次，详细诊断仍保留。剪贴板接收文本与当前内容一致时不再写入，相同内容被管理工具重写时不再重新广播。
- 剪贴板在全部在线、已配对且开启共享的设备间双向同步；不依赖光标在哪台电脑。支持文字、图片内容与文件/文件夹；剪贴板被占用时有限重试，不保存复制历史或在日志输出正文。文件和图片内容通过独立加密通道传输。
- 文件内容只在配对设备间传输，无云端服务器、账号或运行时模型调用。
- 开机启动默认关闭；开启后只写当前用户启动项。
- 更改监听端口需重启；不同端口无法通过同端口广播发现，可手动填 IP:端口。

## 已知范围

- 目前只有 Windows x64 版本，未实现 macOS。
- 不控制 UAC 安全桌面、登录屏幕或权限更高的管理员窗口，不尝试绕过系统限制。
- 不保证游戏、反作弊软件、独占输入程序、远程桌面嵌套场景兼容。
- 不自动安装系统服务，不修改公网路由，不关闭防火墙。
- 屏幕尺寸和设备名称在重新连接后更新到对方，连接期间更改显示器配置后请重新连接。

## 建议验收顺序

1. 两台电脑配对，普通鼠标移动、点击、滚轮和中文输入。
2. 上下左右穿屏以及紧急返回；中途断网时没有粘键。
3. 小文件从 A 桌面拖进 B 的资源管理器，再反向操作。
4. 多选、嵌套文件夹、空目录、同名冲突、大文件。
5. 增加 C，验证 A 控制 B 后将 B 文件拖到 C。

反馈时提供操作方向、Windows 版本、显示缩放、网络类型、具体错误和“复制诊断信息”内容。不要提供配对密钥或证书私钥。
