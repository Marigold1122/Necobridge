# NekoBridge 1.2.3

## 剪贴板快捷面板

移除最小化、最大化、关闭按钮。保留边缘缩放，点击面板外收起；Esc收起（设置展开时先关闭设置）。禁用标题栏双击最大化及系统最小化/最大化命令。唤起时恢复最小化状态并校正位置，防止旧窗口状态只显示一小块。

删除顶部“仅本机”状态文字、旧版本号和底部“双击或Enter使用”说明。版本号从程序集读取。删除加载更多按钮，接近列表底部时自动加载下一页，追加记录不重建整个列表；搜索刷新期间不发出旧结果分页。

主设置与历史齿轮中的条数名称统一为“本机历史保留条数”。在线设备复制的新内容自动共享，接收成功后按各自历史开关和类型设置记录；各端独立执行条数/日期/容量上限。某端清理不删除其他端记录，离线期间历史不补传。

## 包含此前未提交的修改

- 设置中的在线更新：每次启动静默检查，不自动下载或安装。用户点击后下载，准备完成后仍需手动重启更新。使用Velopack便携包，旧普通ZIP需要手动迁入一次；本轮未上传更新索引到GitHub。
- 深色主题保存到本地配置，下次启动恢复。
- 删除主设置中用户指定的三段说明文字。

## 使用

从托盘退出旧程序，完整解压NekoBridge-win-Portable.zip后运行其中的NekoBridge.exe。默认Alt+V打开历史。配对和历史数据不清空。GitHub仍未发布Velopack更新索引，检查更新失败不会影响正常共享。
