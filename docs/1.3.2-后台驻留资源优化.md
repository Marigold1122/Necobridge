# 1.3.2 后台驻留资源优化

包含尚未提交的1.3.1优化，并进一步减少后台持有资源。没有强制GC、EmptyWorkingSet、定时内存清理，也没有关闭共享功能或改变历史保留规则。

## 本轮新增

- 24-DIP Logo改为按96像素解码，可覆盖400%缩放。图标未显示、主窗口最小化时释放Source，恢复后重新读取。不修改原素材。
- 主窗口后台启动、隐藏或最小化时不加载桌面壁纸；隐藏时撤销待回填请求，释放壁纸、排列图形及控件投影。重新显示时按现有状态恢复。
- 隐藏/最小化时停止界面刷新定时器。网络、剪贴板、输入监听和失联释放继续运行。
- 原生拖放STA及辅助窗口延迟到第一次实际拖放调用才创建。未使用过拖放时退出不会为了清理而启动线程；使用后保留成熟的复用逻辑，不增加频繁启停风险。
- 历史列表数据库查询只返回前256个字符的预览，搜索仍针对完整搜索字段。选择复制时按记录ID取回全文，图片原件不变。删除/过期后不能恢复的记录明确报错。

## 局部测量

独立PerformanceSmoke，Release模式，临时数据，无窗口/真实钩子/真实剪贴板/账号数据。对照旧算法与本轮实现：

|项目|之前|之后|
|---|---:|---:|
|24-DIP Logo解码输出像素|2,604,980字节|36,480字节|
|20条约20万字符文本的列表持有文本|8,000,580字节|10,240字节|
|512×8192长图的预览像素（1.3.1已改）|6,553,600字节|9,216字节|
|5设备10万次连接查询分配（1.3.1已改）|84,000,040字节|40字节计时开销|
|3000次4KiB帧读取分配（1.3.1已改）|40,584,040字节|27,288,040字节|

以上不是进程总内存下降值，图片像素也不含解码器临时内存。Logo仍使用原图文件，预览不限制原始历史内容。

当前安装进程没有被停止/替换，没有相同场景的整进程前后比较，不能承诺静息低于60MB。WPF/.NET模块、图形和网络栈仍有基础占用，运行时也可能保留已申请的工作集。

## 检查

- PerformanceSmoke：预览界限、全文搜索和恢复取回、分页/隐藏释放、旧查询不回填、帧错误与取消恢复、未用拖放不启动STA，通过。
- ClipboardSmoke：模拟剪贴板同步/回环/历史与原生临时目标检查，通过；新增用短预览记录恢复完整长文本的检查，通过。没有访问真实系统剪贴板。
- InputSmoke：此前轮盘松键、本地接管、停车隔离、四向边缘及映射，通过。
- 发布编译和压缩包/更新包完整性检查通过。未执行真实桌面、截图或完整测试套件。
