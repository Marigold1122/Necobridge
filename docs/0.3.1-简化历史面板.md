# v0.3.1 简化剪贴板历史面板

仅调整历史面板外观及相应条目动作接线，不改变剪贴板同步、数据库格式或来源文件。

- 顶部搜索与分类，下方单列历史条目；不再使用左右详情工作台。
- 文字、图片与文件信息直接在条目中预览；收藏和删除就地操作。
- 设置收起，默认Alt+V、快捷键修改、保留条数和自动粘贴等功能保留。
- 条目动作使用所在条目参数，不依赖先选中；双击动作排除收藏/删除按钮，避免误复制。
- 外观由指定claude-opus-5-5生成，以脱敏后的主界面作为视觉参考，以EcoPaste截图裁剪部分作为结构参考；未发送真实剪贴板正文。

升级前退出旧版并完整解压。历史数据库继续使用原位置，不清空或迁移用户已有历史。
