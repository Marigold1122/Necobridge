# 1.4.8 开始菜单真实离开对照

## 已验证事实

用户确认两种表现：磁贴悬停亮框残留、导航栏悬停展开不收起。1.4.7捕获修正无效。现场检查确认1.4.7确实运行、隔离窗口命中并持有捕获，排除未更新和SetCapture未生效。

诊断纠正：Windows 8+ EnumWindows仅列桌面应用顶层窗口，漏掉StartMenuExperienceHost。采用GetDesktopWindow/FindWindowEx遍历找到真实菜单句柄，随后直接AutomationElement.FromHandle取得菜单范围。本机菜单宿主覆盖0,0,2560,1390，顶部停车1280,4在其坐标范围内。

真实菜单试验工具tools/StartMenuTrial，无应用点击、无焦点切换，仅指针移动与隔离窗口测试；截图保存在.tools，不提交或上传。试验前取消的仅是caption确认过的产品自身停车窗口捕获，未释放其他应用捕获。结束恢复原光标位置。

截图对照：侧边栏悬停后顶部停车仍展开；直接移动到菜单范围外1394收起且菜单保持打开；回顶部隔离区保持收起。只改到窗口范围外但立即显示隔离层仍失败。先移出、等待120ms再显示隔离层有效。生产路径采用异步Forms.Timer 120ms后显示，不在钩子/输入路由线程sleep。120ms是本机实验参数，不是Windows提供的输入处理完成保证，不能宣称全系统可靠屏障。

最终生产实现独立运行：真实侧边栏展开→调用ParkingPoint/Show/MoveCursor→侧边栏收起；VSCode磁贴亮框→同路径→亮框消失。菜单保持打开。截图对照位于.tools/start-menu-trial-final/final-sidebar.jpg与.tools/start-menu-trial-both/tile-final.jpg。未验证网络双机完整切换及快速往返。

## 修改

- ParkCursor根据光标命中根窗口范围选择屏内停车点：默认顶部，若仍在原窗口内，依次尝试底部、左右；无范围外候选时保持顶部。没有Start进程名特判、不伪造Shell离开消息。
- 移动仍同步完成；隔离窗口异步延迟显示，显示前校验代际、可见意图、实际光标仍在停车区。Hide取消定时器；快速重入/实体接管令过期请求无效。不增加无限重试或周期清理。
- 移除1.4.7没有效果的捕获/释放。原鼠标移动映射和右键记账不变，Alt+V原字体保留。
- 局限：显示延后120ms有短暂光标可见及目的位置悬停风险；无外部空间的真全屏窗口无法按此法提供几何离开。需要真实双机验收，不宣称所有窗口问题已根治。

DepartureSmoke覆盖默认点、开始菜单范围、全屏无候选、普通窗口和负坐标；InputSmoke通过；发布编译成功、ZIP CRC与更新包哈希检查通过。1.4.8仅本地打包，未提交、推送或发布Releases，未替换正在运行的软件。
