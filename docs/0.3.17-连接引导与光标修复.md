# v0.3.17 连接引导与光标修复测试版

## 连接引导

本轮按用户确认的流程直接实现，不依赖此前返回401的设计服务；不声称本轮获得外部模型设计结果。

- 进入连接页先显示“这台主机是作为…”以及控制端/被控端选择。
- 选择角色后，短淡入和上移动画展开圆圈编号、竖向虚线步骤；系统关闭动画时直接显示。
- 被控端：开启配对按钮就在第一步；开启后第二步展开本机地址、安全密钥、复制连接信息与剩余时间。等待控制端连接，连接成功显示第三步排列入口。
- 控制端：第一步提示去对方选择被控端并开启配对；点击下一步，第二步就地查找设备或手填地址、填写安全密钥、连接。失败在本步骤显示，保留地址，阻止重复连接；真正连接成功后展开第三步。
- 所有按钮与输入框位于对应步骤，不再要求跳到右侧。
- 下方折叠区保留已配对设备的重新连接、屏幕排列及移除；重连不要求填写配对密钥。角色选择只影响引导，不创建永久主控身份或更改权限。
- 保留原白色/青柠样式、设置及原屏幕排列外观，默认打开连接页。

## 光标修复

包含0.3.16-cursor的修改：离开被控设备后保持停车隔离；在线未暂停设备保持心跳；停车窗口显示后刷新命中，减少浏览器顶部标签悬停残留。恢复路径包括重新进入、物理接管、紧急返回、暂停、失联与退出。实机效果仍需双机验收。

## 验证

仅必要Release发布编译、连接页结构与事件检查、排列XAML基线一致性及差异检查；未运行完整测试、截图或真实多机功能验收。未读取真实剪贴板数据或修改用户配置，未提交或推送。

## 测试方式

两端退出旧进程，再运行同一版本：

1. B选被控端，点开启配对；确认地址密钥在第二步出现。
2. A选控制端，按步骤发现或填写B的地址密钥并连接；失败信息应留在第二步，成功后出现排列按钮。
3. 调整左右顺序并来回穿屏，确认B在A恢复本机控制后隐藏光标且不保留浏览器标签悬停。
4. 重连已有设备、切换引导角色、关闭/到期后重新开启配对；确认旧设备连接与排列不被清空。

“复制连接信息”会将密钥放入系统剪贴板；已开启剪贴板历史或同步时，内容可能被记录或同步。敏感信息可直接查看并手动填写，不必使用复制。
