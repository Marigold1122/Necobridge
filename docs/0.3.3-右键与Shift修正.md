# v0.3.3 右键重放与Shift状态修正

## 定位

本机独立原生窗口中，NekoBridge标记的右键注入后，观察到额外的已注入右键事件（ExtraInfo=0x53544152）。本机运行StarPie，其公开实现使用该标记重放手势触发键。旧版会把第三方重放误认成本地实体接管，导致yield、释放Shift及主控恢复边缘位置，可能随后再次穿屏。

同一检查确认VK_LSHIFT按下可在菜单Opened和持续等待期间保持，不能把问题归为不支持Shift长按或Windows10菜单不可用。

## 修正范围

输入事件保留来源信息。当前被远端控制时，第三方软件注入事件正常交给系统，但不触发本地接管、不更改实体按键状态。主控仍转发厂商驱动生成的快捷键/媒体键；NekoBridge自身注入继续排除以避免回环。真实本地鼠标移动/键盘操作仍能取回控制权。

不对StarPie硬编码进程或标记，不关闭、卸载其进程，不修改用户驱动设置；没有按未经证实的OS鼠标warp假设屏蔽事件。已确认可用的顶部停放、文件传输、剪贴板和历史界面保持不变。

本机复现与隔离检查不等于右侧电脑的全部硬件/驱动组合已验收，两端均升级后检查右键和持续Shift+右键即可。
